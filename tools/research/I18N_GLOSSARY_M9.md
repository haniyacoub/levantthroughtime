# Extra glossary for this round (peoples, religions, languages)

Use these forms consistently (Arabic / Hebrew):
- Samarians (people of the Assyrian-Persian province of Samaria) → أهل السامرة / תושבי שומרון.  Samaritans (the religious community) → السامريون / השומרונים. Never confuse the two.
- Idumeans → الإدوميون / האדומים (אידומאים).  Edomites → الأدوميون / האדומים.
- Judahites → أهل يهوذا / היהודאים (בני ממלכת יהודה). Judeans / Jews → اليهوديون / اليهود ; יהודים
- Musta'arabim → المستعربون / המוסתערבים.  Sephardi → السفارديم / הספרדים.  Ashkenazi → الأشكناز / האשכנזים.  Mizrahi → المزراحيم / המזרחים.
- Bahá'ís → البهائيون / הבהאים. Bahá'u'lláh → بهاء الله / בהאא אללה. 'Abdu'l-Bahá → عبد البهاء / עבדול-בהאא.
- Ahmadis / Ahmadiyya → الأحمديون / الأحمدية ; האחמדים / האחמדייה. Kababir → الكبابير / כבאביר.
- Dom (Nawar) → الدوم (النَّوَر) / הדום (נוואר). Domari → الدومرية / דומארית.
- Afro-Palestinians → الفلسطينيون الأفارقة / אפרו-פלסטינים.  Maghrebi community / Mughrabi Quarter → المغاربة / حارة المغاربة ; המוגרבים / שכונת המוגרבים.
- German Templers → التمبلريون الألمان / הטמפלרים הגרמנים.  Brotherhood of the Holy Sepulchre → أخوية القبر المقدس / אחוות הקבר הקדוש.
- Syriac Orthodox (Jacobite) → السريان الأرثوذكس (اليعاقبة) / הסורים האורתודוקסים (היעקובים). Copts → الأقباط / הקופטים. Maronites → الموارنة / המרונים.
- Ethiopian Orthodox → الأحباش الأرثوذكس / האתיופים האורתודוקסים.  Beta Israel → بيتا إسرائيل / ביתא ישראל.
- Kurds → الأكراد / הכורדים. Turkmen → التركمان / הטורקמנים. Circassians → الشركس / הצ'רקסים.
- Canaanite → كنعاني / כנעני ; Aramaic → الآرامية / ארמית ; Syriac → السريانية / סורית ; Western Neo-Aramaic → الآرامية الغربية الحديثة / ארמית מערבית חדשה ; Judaeo-Arabic → العربية اليهودية / ערבית-יהודית ; Palestinian Arabic → العربية الفلسطينية / ערבית פלסטינית ; Ancient North Arabian → العربية الشمالية القديمة / ערבית צפונית עתיקה ; Amorite → الأمورية / אמורית.
- Yahweh/YHWH → يهوه / יהוה (keep "YHWH" in Latin letters where the English writes YHWH).  Qos/Qaus → قوس / קוס.  Kemosh → كموش / כמוש. Milkom → ملكوم / מלכום.
- "textual tradition" → الرواية النصية / המסורת הכתובה.  "contributed to" → أسهم في / תרם ל.
